## Codebase Patterns
- Selalu jalankan `npm run typecheck` dan `npm run lint` sebelum melakukan commit.
- Gunakan React state yang bersih dan simpan state persisten (seperti tema) di localStorage.
- Pisahkan komponen UI secara modular dalam subdirektori `src/components`.
